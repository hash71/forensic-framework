# Expert-Annotation Preflight Gate

Complete this checklist privately before sharing any annotation item. The
public repository intentionally contains no reviewer names, contacts,
qualification documents, consent evidence, or payment details.

## Institutional and study approval

- [ ] Responsible institution and accountable investigator identified.
- [ ] Human-participant or equivalent institutional determination recorded.
- [ ] Determination identifier, office/committee, date, and scope verified.
- [ ] Consent information and consent-recording procedure approved.
- [ ] Withdrawal/de-identification cutoff and deletion contact fixed.
- [ ] Data retention, access, encryption, and deletion plan approved.

## Reviewers and independence

- [ ] Two qualified independent DFIR reviewers verified.
- [ ] One distinct qualified adjudicator verified.
- [ ] Qualification categories meet the public minimum criteria.
- [ ] Conflicts with benchmark design, model operation, and authors documented.
- [ ] Opaque reviewer codes assigned separately from identity records.

## Burden and compensation

- [ ] Small instruction-comprehension pilot completed without study labels.
- [ ] Pilot-based time range and maximum item count fixed.
- [ ] Skilled-work compensation, currency, method, and payment timing fixed.
- [ ] Early-withdrawal payment terms fixed and disclosed.
- [ ] Active-visible time measurement disclosed and approved.

## Frozen materials

- [ ] Corrected synthetic run is complete and release-sanitized.
- [ ] Final annotation package contains exactly the planned claim sample.
- [ ] Package manifest, records, cases, items, guide, and admin-key hashes saved.
- [ ] Only `blind/` is shared with the two independent reviewers.
- [ ] Offline review page passes the no-network and inert-content checks.
- [ ] The adjudication package is generated only after both reviewer CSV hashes
      are frozen.

## Completion record

The private coordinator log records completion date, responsible person, and
the hashes of the final approved materials. Any unresolved box blocks label
collection. Never fill a missing institutional decision or reviewer field with
model-generated text.
